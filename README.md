# Exploradores AFM, SEM y Raman

Tres páginas interactivas para explicar el principio de operación de un microscopio de fuerza atómica (AFM), un microscopio electrónico de barrido (SEM) y un espectrómetro Raman. Se prepararon para una visita del curso de Teoría Electromagnética (Ingeniería Aeroespacial, ENES Juriquilla, UNAM) al CFATA.

| Página | Contenido |
|---|---|
| `AFM_explorador.html` | AFM en modo intermitente: barrido de una rejilla de escalones, forma de la punta, perfil medido y lazo de control |
| `SEM_explorador.html` | Formación de la imagen punto por punto (cristales bidimensionales de WSe₂): voltaje, zona barrida, enfoque y detector |
| `Raman_explorador.html` | Dipolo inducido modulado por la vibración: líneas Rayleigh, Stokes y anti-Stokes; picos del MoS₂ |

Cada explorador tiene tres apoyos: un **guion de demostración** bajo la figura (pasos que acomodan los controles; flechas ← → del teclado; botón «Ampliar»), una pestaña de **preguntas** para el grupo y una pestaña **«Para el reporte»**, donde el alumnado anota sus datos, obtiene las cantidades derivadas, descarga la figura y copia un resumen con la cita.

Cada archivo es independiente (HTML, CSS y JavaScript en un solo archivo, sin dependencias externas). `index.html` es la portada.

Los exploradores son modelos simplificados con valores típicos; no reproducen los datos de un equipo en particular.

Autores: Elodie Strupiechonski y Andrés de Luna Bugallo.
